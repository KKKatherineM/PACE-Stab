# ProteinGym common97 application data

This bundle contains the **97 assays / 79 protein identities actually used in
the current PACE-Stab Fig. 6b**, in the frozen figure order. The fixed
training-size comparison cohort contains 91 assays. All files were copied from
existing final-run inputs; no model, regression, performance calculation,
filtering, or split generation was run while packaging.

There are **381,311 assay–variant records** and **9,440
saved assay × training-size × seed configurations**. Counts are not numbers of
independent proteins. Shared proteins and homology flags remain in the
manifest. In particular this is the confirmed homology-included common97
cohort, including GRB2; it is not the earlier GRB2-excluded main83 cohort and
must not be described as entirely independent OOD validation.

## Files

- `assay_manifest.csv`: all 97 IDs, original Fig. 6b labels, figure order,
  metadata, available training sizes, and package-relative paths.
- `common91_manifest.csv`: the frozen common set for all five training sizes.
- `not_in_common91.csv`: the six remaining assays; none were removed from 97.
- `table_s13.csv`: the two-column figure-label / full-assay-ID table.
- `assays/<assay_id>/data.csv.gz`: exact SPURS-distributed experimental table
  consumed by the final downstream run. Columns `seq`, `log_fitness`, `n_mut`,
  and `mutant` retain the original strings and row order. `log_fitness` is the
  stored experimental regression target; this bundle applies no transform.
- `seqs.fasta.gz`: exact corresponding variant-sequence FASTA.
- `population.csv.gz`: frozen `UID`, `mutation`, zero-based `source_row0`, and
  `sequence_sha256`. `UID` is assay ID + `::` + the stored mutation identifier.
- `deepsequence.csv.gz`: the frozen UID-aligned evolutionary scalar (`score`).
  `deepsequence_original_pll.csv.gz` also preserves the original cache read by
  the official loader. Its absolute-versus-WT-offset generation semantics were
  not independently recovered; the stored scores were used unchanged.
- `pace.csv.gz`: the existing UID-aligned PACE M6 stability scalar (`score`),
  positive for destabilization. This is an exception to the other release
  datasets: frozen scalar features are included here to preserve the exact
  downstream inputs. No embeddings, checkpoints, or new predictions are added.
- `splits.tar.gz`: the exact existing train/test/pool CSVs and original
  `split_lock.json`, with archive paths `<assay_id>/<filename>`.
- `split_index.csv`: portable lookup of the original ordered train/test files,
  hashes and configuration IDs. Paths are relative to an extraction directory.
- `protocol/`: both original run protocol locks, preserved verbatim.
- `provenance/`: original feature/execution locks, local source paths and
  SHA256 records, archive-member checksums, and the packaging script.
- `validation.json` and `SHA256SUMS`: packaging checks and payload checksums.

The historical JSON locks intentionally retain original server paths as
provenance. Those paths are not required for reading the bundle: use
`assay_manifest.csv` and `split_index.csv` for portable paths. Original locks
may mention an additional historical comparator; no SPURS-enhanced scores or
results are added by this packaging task.

## Read or extract

Pandas can read the `.csv.gz` tables directly. To inspect an experimental file:

```bash
gzip -dc assays/GRB2_HUMAN_Faure_2021/data.csv.gz | head
```

To extract a saved split archive into a chosen empty output directory:

```bash
mkdir -p /your/output/splits
tar -xzf assays/GRB2_HUMAN_Faure_2021/splits.tar.gz -C /your/output/splits
```

The experimental tables are inputs to the published low-N Ridge application,
**not** `target_ddg` labels for the release's stability evaluator. Base uses
the sequence one-hot representation plus DeepSequence; PACE-enhanced adds one
PACE scalar. One-hot matrices are not bundled. No runnable training workflow
is invoked by this data package, and no historical result is replaced.

Verify compressed payloads from this directory with `sha256sum -c SHA256SUMS`.
Decompressing each copied file reproduces its original bytes and SHA256 listed
in `provenance/source_files.csv`; archive members are similarly documented.

## Provenance and attribution

These are existing ProteinGym experimental datasets as distributed and
preprocessed with [SPURS](https://github.com/luo-group/SPURS), not experiments
newly generated by PACE-Stab. Keep the complete assay IDs and cite the
underlying assay publications, ProteinGym, and the SPURS low-N method when
using these data. Local source versions are pinned by SHA256, rather than
silently replaced by a newer ProteinGym release. The frozen SPURS core
protocol records upstream commit `45cf3d40431f32ee503e2956df08fd3eb0517250`.
